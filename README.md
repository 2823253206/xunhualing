# 寻花令

诗词猜句游戏，单文件 HTML，双击即玩，无需联网与安装。

## 玩法

- 每局从题库中抽一个整句（上句＋下句；词曲为一韵句，可含数小句），逐字猜出。
- 落笔后逐字比对：墨绿为正位，赭黄为含字他处，灰色为此题无。
- 不限次数，直到寻回为止。

## 三个入口

| 入口 | 题池 |
| --- | --- |
| 五言 | 两个五字小句，共十字 |
| 七言 | 两个七字小句，共十四字 |
| 混合 | 五言、七言、词曲混在一池，字数不定，落笔几个字都行 |

## 其他

- 题库内联，取自小学、初中、高中教材诗词曲全文，共 154 篇、698 题。
- 页面内可设题库范围（学段三档 + 逐篇取舍），进度存于浏览器本地。
- 输入三字以上，输入框下方会给出题池内的相近整句，点击即可填入。
- 断句依原文句读：一个整句即一题，上句与下句不会错配。

## 文件

- `寻花令.html`：全部内容（HTML/CSS/JS/题库）内联于一个文件。
